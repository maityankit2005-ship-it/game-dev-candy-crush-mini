# 🍬 Candy Crush Mini

A simple Candy Crush-style matching game made with **HTML, CSS and JavaScript**.

## Features
- 8×8 candy board
- Match 3 or more candies
- Score system
- 30 moves per game
- Automatic candy refill
- Combo matches
- Restart button
- Responsive design for mobile and desktop
- No external libraries required

## How to Run

1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open `index.html` in your browser.

You can also use the **Live Server** extension in VS Code and click **Go Live**.

## Controls

Click one candy and then an adjacent candy to swap them.

Match:
- 3 candies = points
- 4+ candies = more points
- Chain reactions = extra points

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
